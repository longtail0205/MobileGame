# ガチャモン（GACHA MONSTERS）

モンスターを **ガチャで仲間にして**、フィールドを冒険しながら野生モンスターやトレーナーとバトルする、
GBA 風のブラウザゲームです。モンスター・わざ・ガチャ・トレーナー・マップなどのデータは
**ブラウザ上のエディタ（editor.html）で簡単に追加・編集**できます。

- 純粋な HTML / CSS / JavaScript だけで動きます（インストール・ビルド・サーバー不要）。
- 対象ブラウザ: 最新の Google Chrome / Microsoft Edge。
- モンスター名・デザイン・マップ・キャラクター・BGM はすべてオリジナルです。

## 1. 遊び方

1. フォルダ内の **`index.html` をダブルクリック**して、Chrome または Edge で開きます。
2. はじめて遊ぶときは名前を入力します。**無料ガチャ 3 回**がプレゼントされるので、ガチャで最初の仲間を手に入れましょう。
3. 「ぼうけん」タブでフィールドを歩き、草むらで野生モンスターと戦ったり、トレーナーと勝負したりします。
4. 勝つとポイント（◆ pt）がもらえます。ポイントを貯めてガチャを引き、仲間を増やしましょう。

> モンスターを 1 体も持っていないと、町の外（`requireParty` のワープ）には出られません。

### 操作方法

| 操作 | キーボード | 画面パッド |
|---|---|---|
| 移動 | 矢印キー / W A S D | 十字キー |
| 決定・話しかける・調べる（A） | Z / Enter / Space | A ボタン |
| キャンセル（B） | X / Esc / Backspace | B ボタン |
| 走る | B を押しながら移動 | B を押しながら十字キー |
| START | C | ― |

- 向きだけ変えたいときは、方向キーを短く押します。
- メッセージは A / B / クリックで送れます。文字送り中に A を押すと全文を表示します。
- 画面パッドはマウスクリック・タッチでも操作できます。

## 2. 画面（タブ）の説明

画面上部のトップバーに **所持ポイント**・**無料ガチャの残り回数**・**サウンド ON/OFF** が表示されます。

| タブ | 内容 |
|---|---|
| **ぼうけん** | GBA 風のフィールド。移動・会話・バトルはここで行います。バトル中はほかのタブに切り替えられません。 |
| **へんせい** | パーティ（最大 6 体）の編成・並べ替え、所持モンスターの確認、わざの入れ替えなど。 |
| **ガチャ** | バナー（ガチャの種類）を選んで単発・10 連を引きます。提供割合・天井までの回数・履歴も確認できます。 |
| **ずかん** | 見つけた（見た）モンスター・手に入れたモンスターの記録。 |
| **その他** | プレイヤー情報とプレイ記録、設定（メッセージの速さ・サウンド・音量）、セーブデータの書き出し/読み込み/リセット、データエディタへのリンク、操作説明。`config.debug` が `true` のときはデバッグ機能も表示されます。 |

## 3. ゲームシステム

数値は初期設定（`data/config.js` / `data/gacha.js`）の値です。すべてデータを書き換えて調整できます。

### ポイント（◆ pt）の入手

| 方法 | もらえるポイント |
|---|---|
| 野生モンスターに勝つ | `(wildBase 10 + wildPerLevel 3 × 相手のLv) × レア度のポイント倍率` |
| トレーナーに勝つ | トレーナーごとの `reward`（未設定なら `trainerDefault` = 150） |
| フィールドに落ちているポイント | マップの `pickups`（1 回だけ拾える） |
| ログインボーナス | 1 日 1 回、起動時に `loginBonus` = 300 pt（ニューゲームの当日はなし） |
| ガチャの重複（凸が最大のとき） | レア度ごとの返還ポイント（下表） |

### ガチャ

- **単発** 100 pt / **10 連** 1,000 pt。無料ガチャは単発のみ使えます。
- **10 連の最後の 1 回は SR 以上が確定**（`multiGuarantee`）。
- **天井**: SSR 以上が出ないまま 100 回引くと、次は SSR 以上が確定します（`pityCount` / `pityRarity`）。
- **ピックアップ**: バナーの `pickup` に入っているモンスターは、そのレア度が出たときに `pickupRate`（50%）の確率で選ばれます。
- 対象モンスターが 0 体のレア度の確率は、ほかのレア度に自動で振り分けられます。
- 入手したモンスターは Lv5（`startLevel`）から。パーティに空きがあれば自動で加入します。

| レア度 | 名前 | ★ | 提供割合（スタンダード） | 野生ポイント倍率 | 凸最大時の返還 |
|---|---|---|---|---|---|
| N | ノーマル | 1 | 50% | ×1.0 | 10 pt |
| R | レア | 2 | 30% | ×1.3 | 30 pt |
| SR | スーパーレア | 3 | 14% | ×1.6 | 100 pt |
| SSR | ダブルスーパーレア | 4 | 5% | ×2.0 | 300 pt |
| UR | ウルトラレア | 5 | 1% | ×3.0 | 1,000 pt |

**重複したとき（凸 / 限界突破）**: すでに持っているモンスターを引くと「凸」が 1 つ増え、全能力が **+4%**（`limitBreakBonus`）上がります。
凸は最大 **5**（`maxLimitBreak`）。最大のモンスターをさらに引くと、上表の返還ポイントがもらえます。
所持は 1 種類につき 1 体です。

### バトルの基本

- 第 3 世代風のターン制バトルです。わざを選ぶと、**優先度 → すばやさ** の順に行動します（同速はランダム）。
- ダメージは レベル・いりょく・こうげき/ぼうぎょ（とくしゅ わざは とくこう/とくぼう）で計算し、次の補正がかかります。
  - **タイプ相性**（ばつぐん ×2 / いまひとつ ×0.5 / こうかなし ×0。防御側が 2 タイプなら掛け算）
  - **タイプ一致**（わざとモンスターのタイプが同じ）×1.5
  - **急所** 1/16 の確率で ×1.5（`critStage` が高いわざは当たりやすい）
  - 乱数 0.85〜1.00、やけど中の物理わざ ×0.5
- **状態異常**: どく・やけど（毎ターン最大HPの 1/8、やけどは物理半減）/ まひ（すばやさ低下・25% で動けない）/ ねむり（1〜3 ターン）/ こおり（毎ターン 20% で解ける）。
- **PP** がすべて 0 になると「わるあがき」を使います。
- **にげる**: 野生戦のみ。自分のすばやさが相手以上なら必ず成功します。
- **経験値**: 倒した相手の経験値を、場に出たモンスターで分けます。場に出ていないパーティメンバー（ひんし以外）も 50%（`expShareRatio`）もらえます。
- レベルアップで新しいわざを覚えます。わざが 4 つ埋まっているときは、へんせい画面で入れ替えられます。

### 回復と全滅

- 回復してくれる NPC（マップの `heal: true` の NPC）に話しかけると、手持ちが全回復します。最後に回復した場所が「復帰地点」になります。
- 手持ちが全員ひんしになる（全滅）と、「めのまえが まっくらに なった！」→ 復帰地点に戻って全回復します。
  全滅時に失うポイントの割合は `blackoutPointLoss`（初期値 0 = 失わない）です。
- 戦えるモンスターがいないときは、野生もトレーナーも出てきません。

## 5. データ編集ガイド

データはすべて `data/*.js` にあります。**メモ帳などのテキストエディタで直接書き換える**か、
**データエディタ（editor.html）** を使って編集します（おすすめはエディタ。[6 章](#6-データエディタの使い方)）。

直接書き換えるときの注意:

- 文字コードは **UTF-8** で保存してください。
- `'文字'` の引用符や `,`（カンマ）、`{ }` `[ ]` の対応を崩すと、ゲームが起動しなくなります。
- 書き換えたら `tools/datacheck.html` を開くか、エディタの「検証」で、参照切れ（存在しないわざ ID など）がないか確認できます。
- **ID**（`id` やオブジェクトのキー）は英小文字・数字・`_` だけにしてください。セーブデータや他のデータが ID で参照するため、公開後は変えないのが安全です。

### 5.1 モンスター（data/monsters.js）

`GameData.monsters = [ ... ]` の配列に、1 体 = 1 ブロックで並んでいます。
いちばん簡単な追加方法は「似ているモンスターのブロックをまるごとコピーして、配列の最後（`];` の直前）に貼り付け、値を書き換える」ことです。

**完全な例**（実際のデータ No.001 ヒノコン）:

```js
  {
    id: 'hinokon',
    no: 1,
    name: 'ヒノコン',
    rarity: 'N',
    types: ['fire'],
    baseStats: { hp: 44, atk: 58, def: 40, spa: 52, spd: 46, spe: 62 }, // 合計 302
    learnset: [
      { lv: 1, move: 'tackle' },        // たいあたり
      { lv: 1, move: 'growl' },         // なきごえ
      { lv: 5, move: 'ember' },         // ひのこ
      { lv: 10, move: 'flameclaw' },    // もえるツメ
      { lv: 15, move: 'hotbreath' },    // あついいき
      { lv: 21, move: 'quickhit' },     // はやわざ
      { lv: 28, move: 'flamebullet' },  // かえんだん
      { lv: 38, move: 'flarecharge' },  // ほのおのとっしん
    ],
    expGroup: 'medium_fast',
    baseExp: 62,
    image: '',
    backImage: '',
    sprite: { shape: 'quadruped', colors: ['#f07830', '#f8d880', '#a02818'] },
    gacha: true,
    category: 'ひだねモンスター',
    height: 0.4,
    weight: 5.2,
    desc: 'たてがみの ように はえた ほのおが げんきの しるし。うれしい ときほど おおきく もえあがる。',
  },
```

| 項目 | 必須 | 説明 |
|---|---|---|
| `id` | ○ | 内部 ID。英小文字・数字・`_`。ほかと重ならないこと |
| `no` | ○ | 図鑑番号（重ならない整数）。図鑑・一覧はこの順 |
| `name` | ○ | 表示名 |
| `rarity` | ○ | `'N'` `'R'` `'SR'` `'SSR'` `'UR'`（gacha.js の rarities のキー） |
| `types` | ○ | タイプ 1〜2 個。例 `['fire']` / `['water', 'dragon']`（types.js のキー） |
| `baseStats` | ○ | 種族値。`hp` HP / `atk` こうげき / `def` ぼうぎょ / `spa` とくこう / `spd` とくぼう / `spe` すばやさ。合計の目安: N 250〜330 / R 330〜400 / SR 400〜470 / SSR 470〜540 / UR 540〜610 |
| `learnset` | ○ | 覚えるわざ `{ lv: レベル, move: 'わざID' }`。**lv: 1 のわざを最低 1 つ**入れてください（ガチャで入手した直後に使うため） |
| `expGroup` |  | レベルアップの速さ `'fast'` / `'medium_fast'`（省略時）/ `'medium_slow'` / `'slow'` |
| `baseExp` |  | 倒されたときに相手がもらう経験値の基準 |
| `image` |  | 正面画像のパス。`''`（空）なら自動生成ドット絵 |
| `backImage` |  | 背面画像のパス（バトルで自分側に表示）。空なら `image` を左右反転、`image` も空なら自動生成の背面 |
| `sprite` |  | 自動生成ドット絵の調整。`shape` 体型（`blob` まるい / `biped` 2足 / `quadruped` 4足 / `bird` / `fish` / `serpent` へび / `insect` むし / `plant` / `ghost` / `dragon`）、`colors` [メイン, サブ, アクセント]（省略時はタイプ色から自動）、`seed` 数字を変えると模様などが変わる |
| `gacha` |  | `false` にするとガチャに出ない（野生・トレーナー専用） |
| `category` / `height` / `weight` / `desc` |  | 図鑑の分類・高さ(m)・重さ(kg)・説明文 |

- 自動生成のドット絵はシードで固定されるので、毎回同じ見た目になります。レア度が高いほど装飾が豪華になります。
- `gacha` が `false` でなければ、`pool: null` のバナー（スタンダードなど）に自動で登場します。
- モンスターを削除・ID 変更するときは、トレーナーの手持ち・マップの野生・バナーの pool / pickup がその ID を使っていないか確認してください（エディタは自動で警告します）。

#### 画像を使う

1. 画像ファイルを **`assets/monsters/`** に置きます。
   - 推奨: **64x64 ピクセル・背景透過の PNG**（正方形）。ドット絵は拡大縮小してもくっきり表示されます。
2. `image: 'assets/monsters/ファイル名.png'` と書きます（ファイル名の大文字・小文字も一致させてください）。
3. 背面画像を使う場合は、同じように `backImage: 'assets/monsters/ファイル名_back.png'` を書きます。
   背面を省略すると、正面画像を左右反転して使います。
4. 画像が見つからない・読み込めない場合は、自動生成のドット絵で表示されます。

> エディタでは「ファイル選択…」で画像を選ぶと、その場でプレビューできます。
> 「assets/monsters/ファイル名 のパスを設定」を選んだ場合は、同じファイルを `assets/monsters/` にコピーしてください。
> 「データURLとして埋め込む」を選ぶと画像そのものがデータに入るのでコピー不要ですが、データが大きくなります。

### 5.2 わざ（data/moves.js）

`GameData.moves = { わざID: { ... }, ... }` の形です。

```js
  kaminari_kick: {
    name: 'かみなりキック', type: 'electric', category: 'physical',
    power: 85, accuracy: 95, pp: 10,
    effects: [{ kind: 'status', status: 'paralyze', chance: 20 }],
    desc: 'でんきを まとった けりで こうげき。まひさせる ことがある。',
  },
```

| 項目 | 説明 |
|---|---|
| `name` | 表示名 |
| `type` | タイプ ID |
| `category` | `'physical'`（ぶつり: こうげき/ぼうぎょ）/ `'special'`（とくしゅ: とくこう/とくぼう）/ `'status'`（へんか: ダメージなし） |
| `power` | いりょく（へんかわざは 0）。目安: 序盤 35〜50 / 中盤 60〜80 / 終盤 90〜120 |
| `accuracy` | めいちゅう（%）。**0 にすると必中** |
| `pp` | 使える回数 |
| `priority` | （省略可）優先度。1 以上で先制、-1 以下で後攻 |
| `critStage` | （省略可）1 で急所に当たりやすい（1 = 1/8、2 = 1/4、3 以上 = 1/2） |
| `effects` | （省略可）追加効果の配列（下表）。複数書けます |
| `desc` | 説明文 |

**effects の書き方**

| 例 | 意味 |
|---|---|
| `{ kind: 'stat', target: 'foe', stat: 'atk', stages: -1 }` | 相手の こうげき を 1 段階さげる |
| `{ kind: 'stat', target: 'self', stat: 'spe', stages: 2 }` | 自分の すばやさ を 2 段階あげる |
| `{ kind: 'stat', target: 'foe', stat: 'def', stages: -1, chance: 20 }` | 20% で相手の ぼうぎょ をさげる |
| `{ kind: 'status', status: 'burn', chance: 10 }` | 10% で やけど（chance 省略で 100%） |
| `{ kind: 'heal', ratio: 0.5 }` | 自分の最大 HP の 50% を回復 |
| `{ kind: 'drain', ratio: 0.5 }` | 与えたダメージの 50% を回復 |
| `{ kind: 'recoil', ratio: 0.25 }` | 与えたダメージの 25% の反動を受ける |
| `{ kind: 'flinch', chance: 30 }` | 30% で ひるませる（先に行動したときのみ） |
| `{ kind: 'multihit', min: 2, max: 5 }` | 2〜5 回連続で攻撃 |

- `stat`: `atk` こうげき / `def` ぼうぎょ / `spa` とくこう / `spd` とくぼう / `spe` すばやさ / `acc` めいちゅう / `eva` かいひ
- `status`: `poison` どく / `burn` やけど / `paralyze` まひ / `sleep` ねむり / `freeze` こおり
- わざを追加したら、モンスターの `learnset` に `{ lv: 30, move: 'kaminari_kick' }` のように書くと覚えます。

### 5.3 タイプ（data/types.js）

```js
GameData.types = {
  normal: { name: 'ノーマル', color: '#A8A878' },
  fire:   { name: 'ほのお',   color: '#F08030' },
  // ...
};
GameData.typeChart = {
  // 攻撃するわざのタイプ: { 受けるモンスターのタイプ: 倍率 }
  fire: { fire: 0.5, water: 0.5, grass: 2, ice: 2, bug: 2, rock: 0.5, dragon: 0.5, steel: 2 },
  // ...
};
```

- 倍率は `2`（ばつぐん）/ `0.5`（いまひとつ）/ `0`（こうかなし）。**書いていない組み合わせは 1**。
- 新しいタイプを追加するときは、`types` に追加 → `typeChart` に攻撃側の行を追加 → 他のタイプの行にも防御側として書き足します。
- 初期データは 17 タイプ（ノーマル・ほのお・みず・くさ・でんき・こおり・かくとう・どく・じめん・ひこう・エスパー・むし・いわ・ゴースト・ドラゴン・あく・はがね）です。

### 5.4 ガチャ（data/gacha.js）

**レア度** `GameData.rarities`: `name` 表示名 / `color` 色 / `glow` 光の色 / `stars` ★の数 / `pointMult` 野生ポイント倍率 / `refund` 凸最大時の返還 pt / `rainbow` 虹色演出。
`GameData.rarityOrder` はレア度を低い順に並べた配列です（レア度を増やすときは両方に追加）。

**ガチャ設定** `GameData.gacha`:

| 項目 | 初期値 | 説明 |
|---|---|---|
| `singleCost` / `multiCost` / `multiCount` | 100 / 1000 / 10 | 単発・10 連の消費 pt と連数 |
| `multiGuarantee` | `'SR'` | 10 連の最後の 1 回の確定レア度（`null` で確定なし） |
| `pityCount` / `pityRarity` | 100 / `'SSR'` | 天井の回数とレア度（0 で天井なし） |
| `maxLimitBreak` / `limitBreakBonus` | 5 / 0.04 | 凸の上限と、凸 1 つあたりの能力アップ（0.04 = +4%） |
| `startLevel` | 5 | ガチャで入手したときのレベル |

**バナー** `banners`（ガチャ画面に上から順に並びます）:

```js
    {
      id: 'fire_only',
      name: 'ほのお ガチャ',
      desc: 'ほのおタイプ だけが でる！',
      rates: { N: 50, R: 30, SR: 14, SSR: 5, UR: 1 },   // 合計 100（%）
      pool: ['hinokon', 'kamadon', 'kitsunebi', 'kaenryu'], // null = ガチャ対象の全モンスター
      pickup: ['kaenryu'],                                // 出やすくなるモンスター
      pickupRate: 0.5,                                    // そのレア度が出たとき pickup が選ばれる確率
      colors: ['#7a1a08', '#f08030'],                     // バナー背景のグラデーション
    },
```

- `rates` の合計は必ず **100** にしてください。
- `pool` に含まれないレア度（上の例で UR のモンスターがいない場合など）の確率は、ほかのレア度に自動で振り分けられます。

### 5.5 トレーナー（data/trainers.js）

```js
GameData.trainers = {
  route1_kenta: {
    name: 'ケンタ',
    className: 'たんパンこぞう',              // 表示: 「たんパンこぞうの ケンタ」
    look: { skin: '#f8d0a8', hair: '#202020', hairStyle: 'spiky', shirt: '#f0c030', pants: '#3060c0', hat: null },
    image: '',                               // バトル立ち絵（空 = 自動生成）
    party: [ { species: 'hinokon', level: 4 }, { species: 'mizupyon', level: 5, moves: ['tackle'] } ],
    reward: 150,                             // 勝利ポイント
    ai: 'smart',                             // 'smart'（かしこい）/ 'random'
    boss: false,                             // true でボスBGM
    rematch: 'daily',                        // 'never'（1回だけ）/ 'daily'（日付が変わると再戦可）
    intro: ['めが あったら しょうぶだ！'],     // 話しかけ・視線で見つかったとき
    lose: ['くっそー まけた！'],               // プレイヤーが勝ったとき
    win: ['へへん ぼくの かちだね'],           // プレイヤーが負けたとき
    after: ['つぎは まけないからな！'],         // 撃破後に話しかけたとき
  },
};
```

- `party[].moves` は省略可（省略時は、そのレベルまでに覚えたわざの最後の 4 つ）。
- 台詞は配列の 1 要素 = 1 ページ。ページ内の改行は `\n`、`{player}` はプレイヤー名に置き換わります。
- **look（見た目）**: `skin` 肌 / `hair` 髪 / `hairStyle`（`'short'` `'long'` `'spiky'` `'bald'` `'bun'`）/ `shirt` / `pants` / `hat`（色、または `null` でかぶらない）/ `accent`。
  `look.image` に画像を指定すると、その画像をフィールド用スプライトシートとして使います:
  **1 コマ 16x24 を 横 3 コマ（0 = 立ち、1・2 = 歩き）× 縦 4 方向（上から 下・左・右・上）** に並べた画像（全体 48x96。同じ比率で拡大した画像も可）。画像は `assets/characters/` に置きます。
- トレーナーをフィールドに登場させるには、マップの `npcs` に `{ id, x, y, dir, trainer: 'トレーナーID', sight: 4 }` を追加します（見た目はトレーナー側の look を使います）。

### 5.6 マップ（data/maps.js）

```js
GameData.worldStart = { map: 'town1', x: 5, y: 6, dir: 'down' };   // ニューゲームの開始位置
GameData.maps = {
  town1: {
    name: 'はじまりのまち',
    bgm: 'town',          // title town route forest cave gym battleWild battleTrainer battleBoss victory gacha
    border: 'T',          // マップの外側に描くタイル
    indoor: false,
    tiles: [              // 1文字 = 1マス（16x16ドット）。全行を同じ長さにする
      'TTTTT::TTTTT',
      'T....::....T',
      'T.hhh::ccc.T',
      'T.wDw::wDw.T',
    ],
    encounters: { rate: 0.12, table: [ { species: 'hinokon', min: 2, max: 4, weight: 40 } ] },
    warps:   [ { x: 5, y: 0, to: 'route1', tx: 5, ty: 18, dir: 'up', requireParty: true } ],
    npcs:    [ { id: 'n1', x: 3, y: 4, dir: 'down', look: { /* 5.5 と同じ */ }, move: 'still', dialog: ['こんにちは！'] } ],
    signs:   [ { x: 4, y: 7, text: ['はじまりのまち', 'ここから ぼうけんが はじまる'] } ],
    pickups: [ { id: 'town1_p1', x: 2, y: 3, points: 50 } ],
  },
};
```

- 座標 `x, y` はマップ左上が `(0, 0)`。
- **encounters**: 野生モンスター。`encounter` が付いたタイル（草むら `,`・洞窟の床 `u`）を歩くと、1 歩ごとに `rate` の確率で `table` から `weight`（重み）に応じて選ばれ、Lv は `min`〜`max`。`rate` 省略時は config の `encounterRate`（0.12）。
- **warps**: そのマスに乗った瞬間に `to` マップの `(tx, ty)` へ移動。ドア `D`・出口マット `m`・マップの端などに置きます。`requireParty: true` はモンスターを持っていないと通れません。
- **npcs**: `move` は `'still'`（動かない）/ `'turn'`（向きを変える）/ `'wander'`（歩き回る）。
  `heal: true` で回復係、`action: 'gacha'` でガチャタブへ誘導、`trainer: 'ID'` + `sight`（視線のマス数）でトレーナー。
- **signs**: 看板（タイル `S` の上など）。**pickups**: 一度だけ拾えるポイント。`id` は全マップで重ならないようにします。

## 6. データエディタの使い方

**`editor.html` をダブルクリック**して開きます（ゲームの「その他」タブの「エディタを ひらく」からも開けます）。

### 基本の流れ

1. 上部のタブ（モンスター / わざ / ガチャ / トレーナー / タイプ / マップ）で編集したい種類を選びます。
2. 左の一覧から項目を選び、右のフォームで編集します。入力はすぐにデータへ反映されます（タブの ● は「ファイルから変更あり」の印）。
3. 反映方法を選びます。
   - **ゲームに一時反映**（Ctrl+S）: 変更をこのブラウザに保存します。**ゲーム（index.html）を再読み込み**すると反映されます。
     すぐに遊んで確かめたいときに使います。ほかの PC やブラウザには反映されません。
   - **JSファイルを書き出し**: `monsters.js` などの完全なファイルを作ります。「ダウンロード」または「コピー」して、
     **`data/` フォルダの同じ名前のファイルと置き換える**と恒久的に反映されます（元のファイルはバックアップしておくと安心です）。
     置き換えたあとは「一時反映を解除」しておくと確実です。
   - **一時反映を解除**: ゲームを `data/*.js` の標準データに戻します（エディタで編集中の内容は消えません）。
4. 保存・書き出しの前には自動で **検証**（参照切れ・ID の重複・確率の合計など）が行われ、エラーや警告があれば一覧で表示されます。
   ヘッダーの「エラー / 警告」ボタンや「検証」ボタンでいつでも確認できます。

- エディタを開いたとき、以前「一時反映」したデータがあれば「一時反映データを読み込む / ファイルのデータから始める」を選べます。
- 各タブの「ファイルの状態に戻す」で、そのタブの編集を取り消して `data/*.js` の状態に戻せます。
- 保存していない変更があるままページを閉じようとすると、ブラウザが確認します。

### 各タブ

| タブ | できること |
|---|---|
| **モンスター** | 検索・レア度/タイプで絞り込み。基本情報、種族値（合計とレア度の目安を表示）、覚えるわざ（行の追加・削除・並べ替え・レベル順ソート）、画像（パス入力・ファイル選択・即プレビュー）、自動生成ドット絵の体型・色・シード（ランダムボタン・ライブプレビュー）。新規追加（空き No / ID を自動提案）・複製・削除（参照があれば警告し、参照ごと取り除くことも可）。ID を変えると参照も書き換えられます |
| **わざ** | タイプ/分類での絞り込み、使用しているモンスター数の表示、追加効果（effects）の編集（種類を選ぶと必要な項目だけ表示・効果の説明文を自動表示）、覚えるモンスターの一覧。削除時は参照警告 |
| **ガチャ** | レア度（名前・色・★・ポイント倍率・返還pt・虹演出）、ガチャ設定（コスト・確定・天井・凸）、バナー（追加・複製・削除・並べ替え、提供割合の合計100チェック、レア度ごとの対象数と実効確率の目安、pool / pickup をチェックで選択、背景色とプレビュー） |
| **トレーナー** | 手持ち（モンスター・レベル・わざ指定）、台詞、報酬・AI・再戦・ボス、見た目（色ピッカーで変更すると 4 方向のキャラと立ち絵をプレビュー） |
| **タイプ** | 相性表（マスをクリックで 1 → 2 → 0.5 → 0 → 1、右クリックで逆順）、名前・色の変更、タイプの追加・削除 |
| **マップ** | タイルパレットから選んで **クリック / ドラッグで塗る**、塗りつぶし、スポイト（右クリックでも可）、開始位置の設定、元に戻す（Ctrl+Z）、拡大率・グリッド、サイズ変更（右下 / 左上で増減）。ワープ・NPC・看板・ポイント・野生モンスターは JSON で編集（構文チェック付き・入力すると自動で反映）。マップ上にマウスを置くと座標と内容を表示 |

### 画像の追加（エディタから）

モンスターの「ファイル選択…」で画像を選ぶと、次のどちらかを選べます。

- **assets/monsters/ファイル名 のパスを設定**（おすすめ）: パスだけを書き込みます。**画像ファイルを `assets/monsters/` にコピー**してください。
- **データURLとして埋め込む**: 画像そのものをデータに書き込みます（コピー不要）。
  ただし一時反映の保存容量（ブラウザの localStorage、数 MB 程度）を超えると保存できないので、小さな画像向けです。

## 7. セーブデータ

- 進行状況は **ブラウザ（localStorage）に自動で保存**されます（保存キー `gachamon_save_v1`）。同じ PC・同じブラウザで `index.html` を開けば続きから遊べます。
- 「その他」タブの **セーブデータ** から:
  - **ファイルに書き出す / テキストでコピー**: バックアップや別の PC への引っ越しに使います。
  - **ファイルから読み込む / テキストを貼り付けて読み込む**: 書き出したデータを戻します。
  - **リセット**: すべての進行を消して最初から始めます。
- ブラウザの「閲覧データの削除」でサイトデータを消すと、セーブデータも消えます。
- エディタの一時反映データ（保存キー `gachamon_data_override_v1`）はセーブデータとは別に保存されます。

## 8. よくある質問

**Q. エディタで編集したのにゲームが変わらない**
A. 「ゲームに一時反映」を押したあと、ゲームのページを **再読み込み（F5）** してください。
`data/*.js` を置き換えた場合も再読み込みが必要です。

**Q. data/*.js を書き換えたのに反映されない**
A. エディタの一時反映データが残っていると、そのデータ（モンスター・わざなど、反映した種類ごと）が優先されます。
エディタの「一時反映を解除」か、ゲームの「その他」タブの「上書きを かいじょ して 標準データに もどす」を押してください。

**Q. 画像が表示されない（自動生成のドット絵のまま）**
A. パスとファイル名（大文字・小文字・拡張子）が合っているか、ファイルが `assets/monsters/` にあるか確認してください。
画像が読み込めないときは自動生成のドット絵に切り替わります。

**Q. データを書き換えたらゲームが真っ白 / 起動しない**
A. `data/*.js` の書き方（カンマ・引用符・括弧）が崩れている可能性があります。書き換える前のファイルに戻すか、
エディタで書き出したファイルを使ってください。`tools/datacheck.html` で問題の場所を確認できます。

**Q. モンスターを削除したら、持っていたモンスターはどうなる？**
A. データに存在しないモンスターは、読み込み時に所持・パーティから外されます（データに戻せば復帰します）。

**Q. 別の PC でも同じデータで遊びたい**
A. エディタの「JSファイルを書き出し」で `data/*.js` を置き換えたフォルダごとコピーしてください。
進行状況は「その他」タブのセーブデータの書き出し/読み込みで移せます。

**Q. ポイントを増やしてテストしたい**
A. `data/config.js` の `debug: true` のとき、「その他」タブのデバッグ機能でポイント付与などができます。

## 9. 開発者向け

- 内部仕様（モジュール構成・グローバル名・データ構造・API の契約）は **`SPEC.md`** を参照してください。
- 自動テスト: ヘッドレス Chrome ドライバ `tools/cdp.ps1`（書式はファイル冒頭のコメント参照）。

  ```
  powershell -ExecutionPolicy Bypass -File tools\cdp.ps1 -Steps tools\steps\editor-02-flow.json -OutDir out\editor
  ```

  手順ファイルは `tools/steps/*.json`。コンソールエラーや例外があると終了コード 1 になります。
- テスト用 URL パラメータ:
  - ゲーム: `index.html?autostart=1`（名前入力などを省略）、`index.html?tab=gacha`（開くタブ）
  - エディタ: `editor.html?start=file|override`（起動時の選択を省略）、`editor.html?section=maps`（開くタブ）
- エディタのテスト用 API（コンソールから）: `App.editor.generate('monsters.js')`（生成ソース）、
  `App.editor.selfTest()`（生成ソースを評価して現在のデータと一致するか確認）、`App.editor.validate()`、`App.editor.changedKeys()`。
- 一時反映データの形式: `localStorage[GameData.config.overrideKey]` に JSON。トップレベルのキー
  （`monsters`, `moves`, `types`, `typeChart`, `rarities`, `rarityOrder`, `gacha`, `trainers`, `maps`, `worldStart`）ごとに `GameData` を丸ごと置き換えます。
